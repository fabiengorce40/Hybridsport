## Isolation des données

1. **Origine distincte :** `kairo-r51-preview.pages.dev` est un projet Cloudflare Pages séparé. Le navigateur ne partage pas le stockage avec `fabiengorce40.github.io` (production) ni avec `kairo-rc1-test.pages.dev` (TEST).
2. **Défense supplémentaire :** toutes les clés sont préfixées `kairo-r51-preview:` (état, préférence Liste / Grille, son du lecteur). Le service worker utilise son propre cache (`kairo-r51-preview-1`) et ne supprime que ses propres caches. Le manifeste a son propre identifiant (application « REKKA R5.1 », distincte de KAIRO).
3. **Vérifié sur l'URL déployée :**
   - sur une origine partagée simulée, les clés de production et de TEST restent inchangées octet pour octet, les caches de production et de TEST ne sont pas supprimés, et aucune clé n'est écrite hors du préfixe ;
   - origines réelles séparées : les données de production sont invisibles depuis la prévisualisation et intactes après passage ;
   - aucune requête vers une autre origine.

## Utiliser son véritable état sur Android

1. Dans l'application de **production** : Réglages → **Exporter mes données**. C'est une lecture seule : rien n'est modifié.
2. Ouvrir https://kairo-r51-preview.pages.dev/ dans Chrome. Le bandeau violet « REKKA R5.1 — PRÉVISUALISATION · données séparées » est visible.
3. Faire l'accueil minimal, puis Réglages → **Importer mes données** → choisir le fichier exporté.
4. Ouvrir Planning → **Grille**.

La copie importée vit uniquement dans la prévisualisation. Ce que vous y faites ne remonte jamais en production.
