> **Provenance d’une valeur**
> - SOURCE_DERIVED : la valeur vient directement d’une source ;
> - SOURCE_INFORMED : la science soutient le mécanisme ou l’ordre de grandeur, pas cette valeur exacte ;
> - EXPERT_PROPOSED : proposition de conception ;
> - PRODUCT_GUARDRAIL ;
> - TECHNICAL.
