# RUNNING-5F-DECISION-ORDER — ordre des décisions et plan de séance de revue

> **Phase 5F (sections K et L).** Un ordre n’est imposé que lorsqu’il est **logiquement nécessaire** : il évite de faire relire un paramètre devenu inutile. Aucune durée de séance n’est estimée.

## 1. Dépendances nécessaires

| Avant | Après | Pourquoi |
|---|---|---|
| **Choix du périmètre (A / B / C)** | Toutes les décisions « facultatives selon le périmètre » | Le périmètre fixe les décisions obligatoires |
| G1-SCOPE (politique) | G1-NOVICE (politique), G1-RETURN (politique) | Frontière générale des populations d’abord |
| G1-NOVICE (politique) | G1-NOVICE (dose V33) | Inutile si P-R0 n’est pas pris en charge |
| G1-RETURN (politique) | G1-RETURN (dose V34) | Inutile si le contexte n’est pas pris en charge |
| E-RECENTLOAD | E-PROG, E-LOAD | La restauration et le garde-fou s’appuient sur le contexte |
| E-DENSITY | E-QUALITY, E-LONG | L’étiquette HD et la désignation du long run consomment la densité |
| E-PROG | E-LONG | La progression du long run dépend de la règle de progression |
| E-VARIABILITY | E-PACE (option B), E-MODEL | Les plages ou la largeur de prédiction peuvent en dériver |
| E-FIRST | E-RECOVERY, E-QUALITY (option C) | Les récupérations et le minimum ne servent qu’en première exposition |
| Périmètre C (marathon inclus) | E-TAPER (volet marathon) | Sans intérêt sinon |

Indépendantes : G1-PAIN, E-RPE, E-RECENCY.

## 2. Plan de séance de revue

| Bloc | Décisions | Rôles présents |
|---|---|---|
| 1. Périmètre | Choix A / B / C | Produit, sécurité, expert de programmation |
| 2. Frontières de sécurité | G1-SCOPE → G1-PAIN → G1-NOVICE (politique) → G1-RETURN (politique) | Sécurité produit (+ relecture clinique recommandée) |
| 3. Intensité et cibles | E-RPE → E-VARIABILITY → E-PACE → E-MODEL | Expert de programmation |
| 4. Composition et charge | E-RECENCY → E-RECENTLOAD → E-DENSITY → E-LOAD → E-QUALITY | Expert de programmation (+ produit pour E-LOAD) |
| 5. Progression | E-PROG → E-LONG | Expert de programmation |
| 6. Populations et fonctions spéciales | E-FIRST → E-RECOVERY → E-TAPER ; G1-NOVICE (dose V33) ; G1-RETURN (dose V34) | Expert de programmation + cosignature sécurité pour les doses |

**Périmètre A** : blocs 1 à 4 seulement (E-RPE, E-RECENCY, E-RECENTLOAD, E-DENSITY) + politiques du bloc 2.
**Périmètre B** : blocs 1 à 6 sans les doses V33 et V34 ni E-LONG, E-RECOVERY, E-QUALITY (facultatives).
**Périmètre C** : tout.
